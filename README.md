# 播放工具（Android APK 版）

一个安卓手机 App：上半部分左右两个按钮，中间一个音量调节长条（**直接调节手机扬声器/媒体音量**），下半部分留空。

- 左按钮「从一号桌子开始」→ 朗读：小智小智，请按照1号餐桌、2号餐桌的顺序开始清洁。
- 右按钮「从二号桌子开始」→ 朗读：小智小智，请按照2号餐桌、1号餐桌的顺序开始清洁。
- 中间的滑条 → **真正修改手机系统媒体音量（扬声器音量）**，不是网页那种只能调“相对大小”。

---

## 为什么要用 APK

网页（HTML）出于安全限制，**不允许修改手机的系统音量**，只能控制播放声音的相对大小。要“真正”调节扬声器音量，必须做成原生 App（APK），通过安卓的 `AudioManager` 直接改系统媒体音量。本项目就是为此做的原生安卓应用。

---

## 怎么把它变成可安装的 APK

本项目已经是完整的 Android Studio 工程，只差最后一步“编译”。你（或身边会一点电脑的朋友）按下面步骤做即可，**不需要写任何代码**。

### 第 1 步：安装 Android Studio（免费）

1. 打开官网：https://developer.android.com/studio
2. 下载 Windows 版 Android Studio，一路「下一步」默认安装（首次安装会自动下载 Android SDK，需要联网，约 1~2 GB，请耐心等它装完）。

### 第 2 步：打开本项目

1. 启动 Android Studio。
2. 选择 **Open**（打开工程）。
3. 选中本文件夹 `AndroidApp`（里面有 `settings.gradle`、`app` 等），点确定。

### 第 3 步：等待同步

1. 打开后右下角会出现进度条在下载依赖（Gradle、Android SDK 等），**第一次会等几分钟**。
2. 如果弹出提示「Gradle wrapper not found」之类，选择用 Android Studio 自动生成 / 使用本地 Gradle，点确定即可。

### 第 4 步：编译出 APK

1. 顶部菜单：**Build → Build Bundle(s) / APK(s) → Build APK(s)**。
2. 等待编译完成，右下角会弹出提示并给出 APK 所在路径（通常在 `AndroidApp\app\build\outputs\apk\debug\app-debug.apk`）。

### 第 5 步：安装到手机

1. 把 `app-debug.apk` 发到手机（微信/QQ/数据线/网盘都行）。
2. 在手机上点开这个 APK 安装。
3. 首次安装若提示“未知来源/安全风险”，在设置里允许“安装未知应用”即可。

## 手机上的语音（重要）

本 App 用的是安卓系统自带的「文字转语音（TTS）」。绝大多数国产手机自带中文语音，点按钮就能读中文。

如果点按钮没声音、或读成英文：

1. 打开手机「设置 → 更多设置/系统 → 无障碍 → 文字转语音」。
2. 把「首选引擎」设为手机自带的中文引擎，并确保「语言」里有中文（简体）。
3. 个别手机需要安装“Google 文字转语音引擎”并在里面下载中文语音包。

---

## 音量说明

- 中间滑条直接改的是**媒体音量**（播放视频/音乐/语音的那个音量），也就是扬声器音量。
- 手机实体音量键也已被设为控制媒体音量，两者同步。
- 部分较新的安卓系统要求 App 在前台才能改音量，本 App 在点击滑条时正处于前台，所以正常可用。
